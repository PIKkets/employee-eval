# Input / Output (I/O) 정의서

## 1. 로그인
- **Input**: 사번(Login ID), 비밀번호
- **Output**: 권한(Role)에 따른 리다이렉트 URL 분기, 로그인 실패 시 에러 메시지

## 2. 관리자 - 부서 관리
- **Input**: 부서명, 상위 부서 정보 (등록/수정 시) / 부서 ID (삭제 시)
- **Output**: 부서 목록 현황, 성공/실패 메시지

## 3. 관리자 - 사원 관리
- **Input**: 신규 사원 정보 (이름, 사번, 이메일, 초기 비밀번호, 부서, 직급)
- **Output**: 전체 사원 목록 그리드 (페이징), 등록 결과

## 4. 관리자 - 평가요소 관리
- **Input**: 평가유형(성과/역량 등), 요소명, 가중치 (합계 100% 검증 필요)
- **Output**: 항목별 평가 요소 리스트

## 5. 관리자 - 평가자 생성(매핑)
- **Input**: 대상 피평가자 선택, 지정할 평가자 선택, 평가 유형 선택
- **Output**: 현재 매핑된 평가자-피평가자 목록

## 6. 사원(평가자) - 성과, 역량, 다면, 면담 평가
- **Input**: 할당된 피평가자 중 대상 선택, 평가요소별 점수 기입, 항목별 또는 종합 코멘트 (Textarea)
- **Output**: 자신이 평가해야 할 피평가자 리스트(진행 상태 포함), 저장 완료 알림

## 7. 관리자 - 최종 등급 확정
- **Input**: 부서별/개인별 산출된 종합 점수 리뷰, 최종 부여할 등급 (S, A, B, C, D) 선택 혹은 시스템 자동 계산 반영
- **Output**: 부서 및 직급별 등급 분포 가이드라인 대비 실제 분포율, 사원별 최종 등급 리스트

## 8. 시각화 (도식화 부분) - 대시보드
- **Input**: 조회하고자 하는 부서 및 사원 선택 조건
- **Output**: 
  - 부서별 등급 현황 (예: 파이 차트/Bar 차트로 S/A/B/C/D 비율 표기)
  - 사원별 평가 점수 상세 (영역별 점수를 방사형 차트 또는 막대 차트로 표기)
